# Aurora · 个人自媒体工作台

一个本地优先的 Web 工作台，用于管理个人自媒体副业的全流程：选题 → 生产 → 排期 → 数据复盘 → 素材沉淀。

## 特性

- **选题池**：灵感收集、优先级评分、状态流转、标签筛选，一键转为内容
- **内容生产看板**：构思 / 脚本 / 制作 / 已发布四阶段管理，关联选题、截止日期
- **发布日历**：按发布日期和截止日期查看排期，点击日期快速安排
- **数据效果分析**：手动录入播放/互动/涨粉/收益，趋势与平台对比图表
- **素材与脚本库**：脚本、链接、笔记、文件分类管理
- **本地优先**：数据保存在浏览器 IndexedDB，无需账号或服务器，支持 JSON 备份/恢复

所有数据均在当前浏览器页面内手动维护，不依赖平台 API 或 CSV 导入。

## 技术栈

- Vite + React + TypeScript
- IndexedDB（`idb`）
- Recharts（图表）、date-fns（日期）

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址（默认 `http://localhost:5173`）。

## 构建

```bash
npm run build
```

产物位于 `dist/`。

## 数据说明

- 数据存储在浏览器 IndexedDB，数据库名 `aurora-workbench`。
- 清理浏览器数据会导致本地数据丢失，请在「设置」中定期导出 JSON 备份。
- JSON 备份不包含上传文件的二进制内容，文件类素材需单独留存原始文件。
